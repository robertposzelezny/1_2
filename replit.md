# Running the project

This is a static HTML, CSS, and JavaScript project with no package dependencies.
Use the Run button to start the existing `Start application` workflow:
`python3 -m http.server 5000 --bind 0.0.0.0`.
The preview serves `index.html` on port 5000.

Phone-number validation runs when the input changes and loses focus.
Valid numbers must contain exactly nine digits.
